# T-4 - Project page and imprint

There is no public project page (no GitHub Pages) on purpose; the repository README is the front
door. Once a page exists, German law requires an imprint on it (name, address that can be served,
mail `kleinanzeigen-assistant-github@ollornog.de`) and a short privacy note, both on the page and in
both languages.

**Done when:** either no page exists, or the page carries imprint and privacy note.
